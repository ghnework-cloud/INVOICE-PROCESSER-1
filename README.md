# Invoice Processor — Web App
### Deploy for FREE on Streamlit Cloud

---

## STEP 1 — Create GitHub Account
Go to https://github.com and create a free account (if you don't have one)

---

## STEP 2 — Create a New Repository
1. Click the **+** button (top right) → **New repository**
2. Name it: `invoice-processor`
3. Set to **Private** (important — keeps your rules private)
4. Click **Create repository**

---

## STEP 3 — Upload These Files
In your new repository, click **Add file → Upload files** and upload:
- `app.py`
- `processor.py`
- `requirements.txt`

Click **Commit changes**

---

## STEP 4 — Deploy on Streamlit Cloud
1. Go to https://share.streamlit.io
2. Sign in with your GitHub account
3. Click **New app**
4. Select your `invoice-processor` repository
5. Main file path: `app.py`
6. Click **Deploy**

Wait 2-3 minutes → Your app is live! 🎉

---

## YOUR LINK WILL BE:
`https://[yourname]-invoice-processor-app-[hash].streamlit.app`

---

## HOW TO USE
1. Open the link on any device (phone, laptop, iPad)
2. Upload your PDF
3. Click ⚡ PROCESS INVOICES
4. Download the processed PDF

---

## UPDATING RULES
When you add new product codes, just upload the new `processor.py` to GitHub.
The website updates automatically within minutes.
